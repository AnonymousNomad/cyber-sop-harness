# Code of Conduct

## Expected behavior

Be technically precise, professional, and respectful. Assume security research is authorized work performed by competent adults. Give actionable feedback and separate implementation criticism from personal criticism.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's private information.
- Requesting or contributing code for unauthorized access, malware delivery, credential theft, or destruction of systems.
- Sharing credentials, customer data, target data, or confidential engagement evidence in issues, pull requests, or discussions.
- Misrepresenting experimental functionality as production-ready.

## Reporting

Contact the maintainer through GitHub private messaging or a private security advisory. Reports will be handled with discretion. Repeated or serious violations result in blocked participation.

## Enforcement

Maintainers may edit or remove comments, close reports, reject contributions, and block accounts that violate this policy. For security-relevant conduct, coordinate through [SECURITY.md](SECURITY.md).
