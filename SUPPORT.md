# Support

## Usage questions

Open a GitHub issue using the **Question / support** template. Include the operating system, .NET SDK version, exact command, expected result, and actual output. Remove credentials, target names, engagement identifiers, and confidential evidence before posting.

## Security issues

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub private security reporting or contact the maintainer directly.

## Scope

This project supports authorized defensive testing only. Requests for exploit delivery, scope bypass, credential theft, unauthorized targeting, or unrestricted shell execution will be closed.
